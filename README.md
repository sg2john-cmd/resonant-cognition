## ⚙️ Running the Python Core Engine (Local Execution)

To run the prototype backend on your local workstation:

1. Clone or download `resonant_engine.py` to your directory.
2. Install dependencies:
   ```bash
   pip install numpy
   ```
3. Execute the script:
   ```bash
   python resonant_engine.py
   ```

## 🛠️ Running the Interactive Prototype Visualizer

1. Clone or download `resonant_simulation.html` onto your system.
2. Open the file in any modern web browser to interact with the live tracking modules.
